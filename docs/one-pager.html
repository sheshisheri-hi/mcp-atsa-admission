Check the MCP tool server
at the door.

TLS reached the endpoint. OAuth issued a badge. This CPU-only ATSA gate asks the third question: may this host treat that server as a tool provider — before any dispatch. Code: github.com/sheshisheri-hi/mcp-atsa-admission

OAuth = badge

The user may use this server. Official MCP today stops here.

ATSA = door check

Draft SEP-2809. Verify a signed clearance against a pinned trust root at connect time.

ACLE = sticky note

Research paper. Re-check the real server + exact action on each risky call. Cited, not built.

Before → after

Before

  • Identity + tools/list on faith
  • Prompt injection drives any connected tool
  • No host-side “may I use this provider?”
→

After

  • Signed clearance vs pinned trust root
  • Admit ≠ every tool is authorized
  • Deny stops dispatch; audit keeps the chain
